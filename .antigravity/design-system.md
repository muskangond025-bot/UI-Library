# Design System — UI Section Library

## 1. Purpose

This design system defines the visual language for the reusable UI section library.

Every section should feel like part of the same product ecosystem.

The goal is a visual system that is:

- premium
- editorial
- modern
- confident
- spacious
- refined
- product-focused
- responsive
- memorable without being noisy

"Award-style" means strong composition, typography, spacing, imagery, interaction quality, and visual hierarchy.

It does not mean:
- excessive animation
- random gradients
- excessive glassmorphism
- unnecessary parallax
- decorative effects everywhere
- oversized typography without purpose
- excessive rounded cards
- visual noise

## 2. Design Priority

When making visual decisions, use this priority:

1. Content clarity
2. Visual hierarchy
3. Layout consistency
4. Responsive behavior
5. Typography
6. Spacing
7. Imagery
8. Interaction quality
9. Motion
10. Decorative details

Do not sacrifice usability or consistency for visual experimentation.

## 3. Layout System

Use a consistent container system.

Preferred maximum content width:

```text
max-w-[1600px]
```
